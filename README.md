# P0 TrendsIA — Comunicados escolares

## Objetivo

Ajudar a equipe gestora a extrair ações, responsáveis e prazos de comunicados escolares. O projeto prevê um programa em Python que recebe o comunicado no terminal e consulta um modelo de linguagem por API. Quando um dado estiver ausente no texto, a saída deve indicar **Não informado**.

## Primeiro caso de teste

Comunicado fictício: “A secretaria deve atualizar o inventário de tablets até 30/11/2026. A coordenação deve avisar os professores sobre a atualização.”

| Ação | Responsável | Prazo |
| --- | --- | --- |
| Atualizar o inventário de tablets | Secretaria | 30/11/2026 |
| Avisar os professores sobre a atualização | Coordenação | Não informado |
